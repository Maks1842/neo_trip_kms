# CLAUDE.md — Neo Trip CRM

Ядро CRM для туристического бизнеса. Дополняет глобальный `~/.claude/CLAUDE.md`:
общие правила оттуда действуют и здесь без повторения.

## Роль и стек

Senior fullstack-разработчик. Приоритеты: корректность и типобезопасность > читаемость >
производительность.

- **Backend:** Python 3.13, FastAPI, SQLAlchemy 2.0 (async, стиль `Mapped`/`mapped_column`),
  asyncpg, Alembic, Pydantic v2.
- **Frontend:** Vue 3.5 (только Composition API + `<script setup lang="ts">`), TypeScript strict,
  Vite, Pinia (setup-style), Vue Router, PrimeVue 5 (тема Aura, styled mode), Tailwind 4.
- **БД:** PostgreSQL 18 в Docker.

**Менеджер зависимостей backend — uv, а не Poetry.** Это осознанное отступление от
инструкции `claude-backend-fastapi.md`: uv быстрее, сам управляет версией Python и `.venv`.

## Команды

Backend (из `backend/`):

```bash
uv sync                                   # зависимости в .venv
uv run uvicorn app.main:app --reload      # запуск
uv run alembic upgrade head               # применить миграции
uv run python -m scripts.seed             # компания, роли, администратор (идемпотентно)
uv run ruff check . && uv run mypy app    # линт и типы
uv run pytest                             # тесты
```

Frontend (из `frontend/`):

```bash
npm run dev          # dev-сервер на 5173 с проксированием /api на backend
npm run build        # vue-tsc + сборка
npm run lint         # ESLint с автоисправлением
```

Инфраструктура (из корня):

```bash
docker compose up -d db     # только PostgreSQL; backend и frontend — под профилем prod
```

**Node 22 ставится через fnm** в `~/.local/share/fnm`, системный Node 18 не трогается.
Перед npm-командами в новой сессии:

```bash
export PATH="$HOME/.local/share/fnm:$PATH" && eval "$(fnm env --shell bash)"
```

**ВАЖНО:** база слушает порт **5434**, а не 5432 — стандартный порт занят системным
PostgreSQL, а 5433 другим сервисом.

## Стиль кода и конвенции

- **Комментарии и docstring'и — на русском.** Комментарий пишется только там, где
  объясняет неочевидное решение, а не пересказывает код.
- Роутер не обращается к БД напрямую: `router → service → repository`.
- Сервисный слой не знает про HTTP: поднимает доменные исключения из
  `app/core/exceptions.py`, а не `HTTPException`.
- **Транзакцией владеет зависимость `get_db`.** Репозитории делают только `flush()`.
  Единственное исключение — отзыв скомпрометированных refresh-токенов в
  `AuthService.refresh`: там нужен явный `commit()`, потому что следом поднимается
  исключение, и откат потерял бы отзыв.
- **Кастомных стилей в `.vue`-файлах нет.** Всё — в `frontend/src/assets/styles/`.
  В компонентах допустимы только классы оттуда, утилиты Tailwind и токены темы
  PrimeVue (`--p-*`). Хардкод цветов запрещён.
- Уведомления показываются только через `useNotify()`, не через `toast.add` напрямую.

## Тестирование

pytest + pytest-asyncio (`asyncio_mode = "auto"`). Текущие тесты не требуют БД:
проверяют целостность схемы, конвертацию денег и генерацию идентификаторов.

```bash
uv run pytest                          # весь набор
uv run pytest tests/test_money.py -v   # один файл
```

**ВАЖНО:** тесты запускать только после явного согласия пользователя.

Интеграционных тестов с реальной БД пока нет — это следующий шаг.

## Архитектура и решения

- **Первичные ключи — UUIDv7 везде**, генерация в Python (`app/common/ids.py`), не в БД:
  клиент должен уметь создать запись и знать её идентификатор до синхронизации.
- **`company_id` во всех таблицах**, кроме глобальных справочников (`countries`, `cities`,
  `currencies`) и `companies`/`refresh_tokens`. Мультитенантность заложена с первого дня:
  добавить её позже без миграции данных практически невозможно.
- **Изоляция тенантов реализована только в `CRUDService._tenant_clause()`.** Конкретные
  сервисы никогда не пишут условие по `company_id` руками — забытый фильтр это самый
  вероятный способ показать одной компании данные другой.
- **Деньги хранятся целыми в минимальных единицах** (`*_minor`, `BigInteger`), в API
  передаются в основных единицах через `app/common/money.py`. Число знаков берётся
  из справочника валют.
- **Однотипные CRUD собираются фабриками**: `build_crud_router` на backend и компонент
  `ReferenceCrud.vue` на frontend. Десять справочников, написанных вручную, — это
  дублирование и десять мест, где можно забыть проверку прав.
- **Права** — плоский список строковых кодов `<домен>.<действие>` в `roles.permissions`;
  `*` означает полный доступ.
- **Профиль и права фронтенд запрашивает через `/auth/me`**, а не достаёт из JWT:
  содержимое токена не должно быть источником решений о доступе.
- **Refresh-токены хранятся хешем**, с ротацией и отзывом всей цепочки при попытке
  повторного использования.
- **Soft delete отсутствует.** Записи, которые нельзя удалять, деактивируются флагом
  `is_active`.

## Окружение

`.env` в корне репозитория (см. `.env.example`), в git не попадает. Обязательны:
`POSTGRES_PASSWORD`, `JWT_SECRET_KEY`, `FIRST_ADMIN_PASSWORD`.

Backend читает `.env` из корня репозитория, а не из `backend/`.

## Известные грабли

- **Взаимные внешние ключи `leads` ↔ `clients`** объявлены с `use_alter=True`. Alembic
  вписывает их в `create_table`, но при выполнении они молча пропускаются — в начальной
  миграции добавлены явные `op.create_foreign_key` в конце `upgrade()` и `op.drop_constraint`
  в начале `downgrade()`. При пересоздании миграции с нуля это нужно повторить.
- **Все модели должны импортироваться в `app/db/registry.py`.** SQLAlchemy разрешает связи
  по строковым именам классов: без полного набора маппинг `User → RefreshToken` не собирается,
  а Alembic не увидит часть таблиц. Реестр импортируется в `main.py` и `scripts/seed.py`.
  Тест `tests/test_schema.py` следит за полнотой списка.
- **Колонка называется `sort_order`, а не `order`** — `order` зарезервированное слово SQL.
- **Уникальность `(company_id, funnel_type, sort_order)` объявлена DEFERRABLE** — иначе
  перестановка этапов воронки падала бы на промежуточном шаге.
- **После `UPDATE` объект нужно `refresh()`**, если он сериализуется в ответ: поле
  `updated_at` пересчитывается сервером и помечается устаревшим, а сессия к моменту
  сериализации уже закрыта (`DetachedInstanceError`).
- **`EmailStr` отвергает домены `.local`** как зарезервированные — в примерах и тестовых
  данных используется `neotrip.ru`.
- **Ruff-правила RUF001–RUF003 отключены**: они срабатывают на каждую русскую букву
  в строках и комментариях.
- **`lazy="raise"` на всех связях по умолчанию.** Нужные связи грузятся явно
  (`selectinload`), иначе в async-коде ленивая подгрузка даёт `MissingGreenlet`.
